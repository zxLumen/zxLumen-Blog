# 2026-11-06 502 事件

## 时间窗
2026-11-06，3 次 502 全部落在 81 秒窗口内（同一时段，集中爆发，非全天散布）。

## 次数
3 次，占全量请求 0.09%。

## 特征
- 响应耗时 1ms —— 远低于正常上游处理时间，属于立即失败而非超时。
- 返回 0B 响应体 —— 无任何上游内容，连接被动断开。
- 三次请求特征一致，可判定为同一原因。

## 判定理由
1ms + 0B 的组合排除了应用慢响应、业务异常和超时重试路径：耗时不足以完成一次正常的 Caddy → 上游转发，说明请求根本没被上游处理就断了。
结论：上游未响应，直接断连（upstream connection closed / 不可用），属于瞬时可用性问题。

## 为什么暂不处理
- 未触发用户侧的重试告警，占比仅 0.09%，影响面可忽略。
- 故障已恢复，当前无持续复现。
- 在无证据指向具体根因前动手改配置，风险大于收益，且容易掩盖真实原因。
